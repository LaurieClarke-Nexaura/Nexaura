Nexaura Homepage Live Interim v4

Purpose
- Next live review version incorporating feedback from Spen and external LinkedIn validation, plus the sharpened Challenger reframe.

Key changes from v3
- Keeps the existing hero, locked wave visual, Negative Compounding Loop and overall homepage architecture.
- Expands the intersection reframe with concrete examples showing how reasonable interventions can improve one part while weakening the whole.
- Adds six selected examples across people/headcount, technology, efficiency/adaptability, burnout/human performance, strategy/differentiation and AI/customer experience. Symptom-shifting is captured as the bridge into the examples; other loops such as trust/control remain part of the broader Negative Compounding Loop library rather than crowding the homepage.
- Sharpens the loop introduction: an intervention may work locally and still compound a system problem.
- Sharpens the Performance Design bridge: start with the result that matters, find the real constraint, then examine Direction, Execution and Capacity around it.
